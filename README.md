# 📊 Superstore Sales Dashboard — Power BI Project

An end-to-end sales analytics dashboard built entirely in Power BI, using Power Query for data cleaning and transformation, based on the popular Superstore dataset.

## 🛠️ Tools Used
- Power BI – Data cleaning & transformation (Power Query), data modeling, DAX measures, and interactive dashboard design

## 📂 Dataset
Superstore Sales Dataset (sourced from Kaggle)

## 📈 Dashboard Pages

### 1. Overview
- Total Sales: 2.30M | Total Profit: 286.40K | Total Orders: 5009 | YOY Growth: 46.88%
- Sales trend (2014–2017), sales by region, category, and sub-category
- Insight: West region leads sales at 0.73M

### 2. Product Analysis
- Best-selling product: Canon image CLASS 2200 Advanced Copier
- Top margin category: Technology
- Discount vs Profit correlation analysis
- Category-wise profit margin breakdown

### 3. Customer Analysis
- Total Customers: 793 | Avg Sales per Customer: 2.90K | Avg Order Value: 458.61
- Segment-wise sales distribution (Consumer 50.56%, Corporate 30.74%, Home Office 18.7%)
- Top 10 customers by sales
- Detailed customer performance table

## 🔑 Key Insights
- Consumer segment contributes over 50% of total sales
- Technology category has the highest profit margin (17.40%)
- West region is the top-performing region
- Sales show strong growth from 2014 to 2017
